# 📝 To-Do List

Uma aplicação de lista de tarefas desenvolvida para auxiliar na organização das atividades do dia a dia.

## 📌 Funcionalidades

- ➕ Adicionar novas tarefas
- ✅ Marcar tarefas como concluídas
- 🗑️ Remover tarefas
- ✏️ Editar tarefas
- 📱 Interface responsiva
- 💾 Persistência de dados (se utilizar LocalStorage)

## 🛠️ Tecnologias Utilizadas

- React.js
- JavaScript
- HTML5
- CSS3

## 📂 Estrutura do Projeto

```
src/
├── components/
├── pages/
├── assets/
├── App.js
└── index.js
```

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Node.js instalado
- npm ou yarn

### Instalação

Clone o repositório:

```bash
git clone https://github.com/maju2107/To-do-list.git
```

Acesse a pasta do projeto:

```bash
cd To-do-list
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm start
```

O projeto estará disponível em:

```text
http://localhost:3000
```

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de React, como:

- Componentização
- Gerenciamento de estado
- Manipulação de eventos
- Renderização dinâmica de listas
